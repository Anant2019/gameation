Automatic Night Lamp using LDR Sensor and Arduino

Beginner8 min buildParts about ₹620Arduino Uno R3

The lamp switches on when the room gets dark and off when there is daylight, like a street light. It teaches how a light sensor and a relay work together.

How it works

  1. The LDR module gives a light level on analog pin A0.
  2. The Arduino compares it with a threshold (40%).
  3. Below the threshold it switches the relay on pin D5, which turns the bulb on.
  4. In daylight the reading rises above the threshold and the relay switches the bulb off.

The logic in one line: IF A0 < 40 → D5 = 1 (else 0).

Arduino code

Generated from the working circuit in the simulator.
// Circuit Arena — Automatic Night Lamp
// Board: Arduino Uno R3
// Wiring:
//   LDR VCC -> Uno 5V
//   LDR GND -> Uno GND
//   LDR OUT -> Uno A0
//   Smart bulb VCC -> Uno 5V
//   Smart bulb GND -> Uno GND
//   Smart bulb SIG -> Uno D5

float v_A0 = 0;   // LDR

void writeOut(int pin, float value) {
  if (value > 1) analogWrite(pin, constrain(value, 0, 255));   // PWM on D3, D5, D6, D9, D10, D11
  else digitalWrite(pin, value > 0 ? HIGH : LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(5, OUTPUT);   // Smart bulb
}

void loop() {
  // 1. Read the sensors
  v_A0 = map(analogRead(A0), 0, 1023, 0, 100);   // light %
  Serial.println(String("A0=") + v_A0);

  // 2. Apply the rules
  if (v_A0 < 40) {
    writeOut(5, 1);
  } else {
    writeOut(5, 0);
  }

  delay(50);
}

Tips for building the real thing

  • LDR OUT goes to analog pin A0.
  • Relay bulb SIG goes to D5.
  • Keep the LDR away from the bulb, or the lamp will see its own light and flicker.
  • Mains (230 V) wiring is dangerous: practise with a 5 V LED strip first, and ask an adult or teacher for mains work.

FAQ

What is an LDR?

A light-dependent resistor. Its resistance falls as light gets brighter, so the voltage on the Arduino pin changes with light.

Can I make a night lamp without Arduino?

Yes, with an LDR, a transistor (BC547) and a relay. The Arduino version lets you change the threshold in code.
