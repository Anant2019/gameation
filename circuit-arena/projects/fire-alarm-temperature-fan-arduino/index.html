Smart Fan and Fire Alarm using Arduino and Temperature Sensor

Intermediate15 min buildParts about ₹750Arduino Uno R3

One temperature sensor controls two outputs: the fan starts above 30 °C and the buzzer alarm sounds above 45 °C. It shows how to use two thresholds on one sensor.

How it works

  1. The DHT11 sensor reports the temperature to the Arduino.
  2. Above 30 °C the Arduino switches the fan on.
  3. Above 45 °C it also switches the alarm on.
  4. When it cools down, both turn off again.

The logic in one line: IF A0 > 30 → D5 = 1 (else 0); IF A0 > 45 → D6 = 1 (else 0).

Arduino code

Generated from the working circuit in the simulator.
// Circuit Arena — Smart Fan + Fire Alarm
// Board: Arduino Uno R3
// Wiring:
//   DHT11 VCC -> Uno 5V
//   DHT11 GND -> Uno GND
//   DHT11 OUT -> Uno A0
//   Fan VCC -> Uno 5V
//   Fan GND -> Uno GND
//   Fan SIG -> Uno D5
//   Alarm VCC -> Uno 5V
//   Alarm GND -> Uno GND
//   Alarm SIG -> Uno D6

#include <DHT.h>

DHT dht(A0, DHT11);
float v_A0 = 0;   // DHT11

void writeOut(int pin, float value) {
  if (value > 1) analogWrite(pin, constrain(value, 0, 255));   // PWM on D3, D5, D6, D9, D10, D11
  else digitalWrite(pin, value > 0 ? HIGH : LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(5, OUTPUT);   // Fan
  pinMode(6, OUTPUT);   // Alarm
  dht.begin();
}

void loop() {
  // 1. Read the sensors
  v_A0 = dht.readTemperature();   // °C
  Serial.println(String("A0=") + v_A0);

  // 2. Apply the rules
  if (v_A0 > 30) {
    writeOut(5, 1);
  } else {
    writeOut(5, 0);
  }
  if (v_A0 > 45) {
    writeOut(6, 1);
  } else {
    writeOut(6, 0);
  }

  delay(50);
}

Tips for building the real thing

  • The DHT11 data pin goes to A0 (A0 also works as a digital pin).
  • For a real fire alarm use a flame sensor or smoke (MQ-2) sensor as well: temperature alone reacts late.
  • Drive a real fan through a relay or MOSFET, never straight from an Arduino pin.

FAQ

Which sensor is best for a fire alarm project?

A flame sensor reacts fastest, an MQ-2 detects smoke, and a DHT11 or LM35 measures temperature. Many projects combine two of them.

What is the range of DHT11?

0–50 °C with about ±2 °C accuracy. Use a DHT22 or LM35 for higher temperatures.
