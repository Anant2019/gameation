How it works

  1. Each LED is connected to its own Arduino pin through a 220 Ω resistor.
  2. The code switches one LED on at a time and moves to the next every 1.5 seconds.
  3. The loop repeats forever, just like a real signal.

The logic in one line: Always: D2 = eq(cycle(1500,3),0); Always: D4 = eq(cycle(1500,3),1); Always: D3 = eq(cycle(1500,3),2).

Arduino code

Generated from the working circuit in the simulator.
// Circuit Arena — Traffic Light
// Board: Arduino Uno R3
// Wiring:
//   Uno D2 -> 220Ω A
//   220Ω B -> LED red +
//   LED red - -> Uno GND
//   Uno D3 -> 220Ω A
//   220Ω B -> LED yellow +
//   LED yellow - -> Uno GND
//   Uno D4 -> 220Ω A
//   220Ω B -> LED green +
//   LED green - -> Uno GND


int cycle(unsigned long ms, int n) { return (millis() / ms) % n; }
int eq(float a, float b) { return a == b; }
void writeOut(int pin, float value) {
  if (value > 1) analogWrite(pin, constrain(value, 0, 255));   // PWM on D3, D5, D6, D9, D10, D11
  else digitalWrite(pin, value > 0 ? HIGH : LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(2, OUTPUT);   // output
  pinMode(4, OUTPUT);   // output
  pinMode(3, OUTPUT);   // output
}

void loop() {
  // 1. Read the sensors

  // 2. Apply the rules
  writeOut(2, eq(cycle(1500,3),0));
  writeOut(4, eq(cycle(1500,3),1));
  writeOut(3, eq(cycle(1500,3),2));

  delay(50);
}

Tips for building the real thing

  • Red on D2, yellow on D3, green on D4, each with a resistor.
  • All three LED short legs go to GND.
  • The long leg of the LED (+) goes towards the resistor and the Arduino pin.
  • Never connect an LED straight to 5 V without a resistor: it burns out.

FAQ

Which resistor is used with an LED on Arduino?

220 Ω to 330 Ω. It keeps the current around 10–15 mA.

How do I add a pedestrian button?

Wire a push button to another pin and, when it is pressed, jump to the red light.
