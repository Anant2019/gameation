How it works

  1. The PIR (HC-SR501) sensor gives 1 on its OUT pin when it sees movement.
  2. The Arduino reads it on a digital pin.
  3. When it is 1, the Arduino switches the alarm on; otherwise the alarm stays off.

The logic in one line: IF D2 = 1 → D6 = 1 (else 0).

Arduino code

Generated from the working circuit in the simulator.
// Circuit Arena — Burglar Alarm (PIR)
// Board: Arduino Uno R3
// Wiring:
//   PIR VCC -> Uno 5V
//   PIR GND -> Uno GND
//   PIR OUT -> Uno D2
//   Alarm VCC -> Uno 5V
//   Alarm GND -> Uno GND
//   Alarm SIG -> Uno D6

float v_D2 = 0;   // PIR

void writeOut(int pin, float value) {
  if (value > 1) analogWrite(pin, constrain(value, 0, 255));   // PWM on D3, D5, D6, D9, D10, D11
  else digitalWrite(pin, value > 0 ? HIGH : LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(2, INPUT);
  pinMode(6, OUTPUT);   // Alarm
}

void loop() {
  // 1. Read the sensors
  v_D2 = digitalRead(2);   // 1 = motion
  Serial.println(String("D2=") + v_D2);

  // 2. Apply the rules
  if (v_D2 == 1) {
    writeOut(6, 1);
  } else {
    writeOut(6, 0);
  }

  delay(50);
}

Tips for building the real thing

  • PIR OUT to D2, buzzer module SIG to D6.
  • The PIR needs about a minute to settle after power-on.
  • Turn the two knobs on the PIR to change how far it sees and how long its output stays on.

FAQ

How does a PIR sensor work?

It detects changes in infrared (heat) from warm bodies moving in front of it. It does not see still objects.

What is the range of a PIR sensor?

About 3–7 metres, adjustable with the sensitivity knob.
