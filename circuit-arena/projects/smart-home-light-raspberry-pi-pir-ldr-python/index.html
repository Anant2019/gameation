Smart Home Light using Raspberry Pi, PIR Sensor and LDR

Intermediate15 min buildParts about ₹4,750Raspberry Pi 4

The light turns on only when both things are true: someone is there and it is dark. It is a simple home-automation project that teaches AND logic and Raspberry Pi GPIO in Python.

How it works

  1. The PIR sensor tells the Pi if someone is moving.
  2. The LDR module tells the Pi if it is dark.
  3. Python code switches the relay on only when both are true.

The logic in one line: IF GPIO17 = 1 AND GPIO27 < 40 → GPIO22 = 1 (else 0).

Python code (Raspberry Pi)

Generated from the working circuit in the simulator.
# Circuit Arena — Smart Home Light (Pi)
# Board: Raspberry Pi 4
# Wiring:
#   PIR VCC -> Pi 4 3V3
#   PIR GND -> Pi 4 GND
#   PIR OUT -> Pi 4 GPIO17
#   LDR VCC -> Pi 4 3V3
#   LDR GND -> Pi 4 GND
#   LDR OUT -> Pi 4 GPIO27
#   Smart bulb VCC -> Pi 4 3V3
#   Smart bulb GND -> Pi 4 GND
#   Smart bulb SIG -> Pi 4 GPIO22

import time
import RPi.GPIO as GPIO

GPIO.setmode(GPIO.BCM)
GPIO.setwarnings(False)
GPIO.setup(17, GPIO.IN)   # PIR
GPIO.setup(27, GPIO.IN)   # LDR
GPIO.setup(22, GPIO.OUT)   # Smart bulb

def map_range(x, a, b, c, d):
    return c + (x - a) * (d - c) / (b - a)

def constrain(x, lo, hi):
    return max(lo, min(hi, x))

def write_out(pin, value):
    GPIO.output(pin, 1 if value > 0 else 0)

try:
    while True:
        v_GPIO17 = GPIO.input(17)
        v_GPIO27 = 0 if GPIO.input(27) else 100   # LDR module DO: HIGH = dark
        if v_GPIO17 == 1 and v_GPIO27 < 40:
            write_out(22, 1)
        else:
            write_out(22, 0)
        time.sleep(0.05)
except KeyboardInterrupt:
    GPIO.cleanup()

Tips for building the real thing

  • Never feed a 5 V signal into a Pi GPIO.
  • On a real Pi use the LDR module DO pin, since the Pi has no analog input.
  • Raspberry Pi GPIO pins are 3.3 V: never connect a 5 V signal to them.
  • The Pi has no analog input, so use the LDR module digital (DO) pin.

FAQ

Which language is used?

Python 3 with the gpiozero or RPi.GPIO library.

Can I do this with Arduino instead?

Yes, and it is cheaper. The Pi is useful if you also want Wi-Fi control or a web dashboard.
