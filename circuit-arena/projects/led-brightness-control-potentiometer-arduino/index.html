How it works

  1. The potentiometer gives a voltage between 0 and 5 V on pin A0, read as 0–1023.
  2. The code maps that number to 0–255.
  3. analogWrite sends PWM to the LED on pin D5: the higher the number, the brighter it looks.

The logic in one line: Always: D5 = map(A0,0,1023,0,255).

Arduino code

Generated from the working circuit in the simulator.
// Circuit Arena — LED Dimmer
// Board: Arduino Uno R3
// Wiring:
//   Pot 10kΩ A -> Uno 5V
//   Pot 10kΩ B -> Uno GND
//   Pot 10kΩ W -> Uno A0
//   Uno D5 -> 220Ω A
//   220Ω B -> LED red +
//   LED red - -> Uno GND

float v_A0 = 0;   // pin A0

void writeOut(int pin, float value) {
  if (value > 1) analogWrite(pin, constrain(value, 0, 255));   // PWM on D3, D5, D6, D9, D10, D11
  else digitalWrite(pin, value > 0 ? HIGH : LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(5, OUTPUT);   // output
}

void loop() {
  // 1. Read the sensors
  v_A0 = analogRead(A0);   // 0–1023
  Serial.println(String("A0=") + v_A0);

  // 2. Apply the rules
  writeOut(5, map(v_A0,0,1023,0,255));

  delay(50);
}

Tips for building the real thing

  • Pot ends go to 5V and GND, the middle pin to A0.
  • D5 is a PWM pin: put the LED there.
  • Use a PWM pin (marked with ~): 3, 5, 6, 9, 10 or 11 on an Uno.

FAQ

What is PWM?

Pulse width modulation: the pin switches on and off very fast. The longer it is on, the brighter the LED looks.

Which potentiometer value should I use?

10 kΩ is the usual choice for Arduino.
