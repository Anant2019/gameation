How it works

  1. The LED is connected to pin D4 through a 220 Ω resistor.
  2. The code switches the pin HIGH (LED on), waits 500 ms, then LOW (LED off) and waits again.
  3. This repeats forever in loop().

The logic in one line: Always: D4 = blink(500).

Arduino code

// Circuit Arena — LED Blink
// Board: Arduino Uno R3
// Wiring:
//   Uno D4 -> 220Ω A
//   220Ω B -> LED red +
//   LED red - -> Uno GND


int blink(unsigned long ms) { return (millis() / ms) % 2; }
void writeOut(int pin, float value) {
  if (value > 1) analogWrite(pin, constrain(value, 0, 255));   // PWM on D3, D5, D6, D9, D10, D11
  else digitalWrite(pin, value > 0 ? HIGH : LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(4, OUTPUT);   // output
}

void loop() {
  // 1. Read the sensors

  // 2. Apply the rules
  writeOut(4, blink(500));

  delay(50);
}

Tips for building the real thing

  • The Arduino runs from USB, so it is already powered.
  • The LED long leg (+) goes toward the resistor, the short leg (−) to GND.
  • Change 500 to 100 for a fast blink or 1000 for a slow one.
  • Most Arduino boards also have a built-in LED on pin 13 you can blink without any wiring.

FAQ

Why do I need a resistor with an LED?

Without it the LED draws too much current and burns out within seconds.

Which pin should I use?

Any digital pin works. Pin 13 has an LED on the board itself.
