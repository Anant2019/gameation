DC Motor Speed Control using MOSFET, Potentiometer and Arduino

Intermediate12 min buildParts about ₹572Arduino Uno R3

A knob sets the motor speed. The Arduino cannot power a motor directly, so a MOSFET switches the battery current while a diode protects the circuit.

How it works

  1. The potentiometer is read on A0.
  2. The Arduino sends PWM to the MOSFET gate.
  3. The MOSFET switches the motor current from the battery on and off very fast, which sets the speed.
  4. A diode across the motor absorbs the voltage spike when the motor switches off.

The logic in one line: Always: D5 = map(A0,0,1023,0,255).

Arduino code

Generated from the working circuit in the simulator.
// Circuit Arena — MOSFET Motor Speed
// Board: Arduino Uno R3
// Wiring:
//   Battery 9V + -> DC motor A
//   DC motor B -> MOSFET D
//   MOSFET S -> Battery 9V -
//   Diode - -> Battery 9V +
//   Diode + -> DC motor B
//   Battery 9V - -> Uno GND
//   Uno D5 -> MOSFET G
//   Pot 10kΩ A -> Uno 5V
//   Pot 10kΩ B -> Uno GND
//   Pot 10kΩ W -> Uno A0

float v_A0 = 0;   // pin A0

void writeOut(int pin, float value) {
  if (value > 1) analogWrite(pin, constrain(value, 0, 255));   // PWM on D3, D5, D6, D9, D10, D11
  else digitalWrite(pin, value > 0 ? HIGH : LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(5, OUTPUT);   // output
}

void loop() {
  // 1. Read the sensors
  v_A0 = analogRead(A0);   // 0–1023
  Serial.println(String("A0=") + v_A0);

  // 2. Apply the rules
  writeOut(5, map(v_A0,0,1023,0,255));

  delay(50);
}

Tips for building the real thing

  • Battery + → motor A, motor B → MOSFET D, MOSFET S → battery −.
  • Flyback diode across the motor: band (−) toward battery +.
  • Battery − to Arduino GND, D5 to the MOSFET gate.
  • Use a logic-level MOSFET (IRLZ44N) so 5 V from the Arduino turns it fully on.
  • Always fit the flyback diode (1N4007) across the motor, stripe towards +.

FAQ

Why not connect a motor to an Arduino pin?

A pin gives about 20 mA, but a small motor needs 200 mA or more. It would damage the board.

Can I reverse the motor?

Not with one MOSFET. Use an L298N or L293D motor driver for both directions.
