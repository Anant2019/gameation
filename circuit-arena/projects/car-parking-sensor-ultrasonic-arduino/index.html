Intermediate12 min buildParts about ₹543Arduino Uno R3

How it works

  1. The ultrasonic sensor measures the distance to the obstacle.
  2. Closer than 30 cm, the Arduino makes the buzzer beep.
  3. Closer than 15 cm, it also turns on the red LED: stop!
  4. Further away, both stay off.

The logic in one line: IF D2 < 30 → D6 = blink(250) (else 0); IF D2 < 15 → D4 = 1 (else 0).

Arduino code

Generated from the working circuit in the simulator.
// Circuit Arena — Parking Sensor
// Board: Arduino Uno R3
// Wiring:
//   Ultrasonic VCC -> Uno 5V
//   Ultrasonic GND -> Uno GND
//   Ultrasonic OUT -> Uno D2
//   Alarm VCC -> Uno 5V
//   Alarm GND -> Uno GND
//   Alarm SIG -> Uno D6
//   Uno D4 -> 220Ω A
//   220Ω B -> LED red +
//   LED red - -> Uno GND

float v_D2 = 0;   // Ultrasonic

// HC-SR04 with TRIG and ECHO on one pin. With separate pins, pass trigPin and echoPin.
long readUltrasonicCm(int pin) {
  pinMode(pin, OUTPUT); digitalWrite(pin, LOW); delayMicroseconds(2);
  digitalWrite(pin, HIGH); delayMicroseconds(10); digitalWrite(pin, LOW);
  pinMode(pin, INPUT);
  return pulseIn(pin, HIGH, 30000) / 58;   // 58 µs per cm, there and back
}

int blink(unsigned long ms) { return (millis() / ms) % 2; }
void writeOut(int pin, float value) {
  if (value > 1) analogWrite(pin, constrain(value, 0, 255));   // PWM on D3, D5, D6, D9, D10, D11
  else digitalWrite(pin, value > 0 ? HIGH : LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(6, OUTPUT);   // Alarm
  pinMode(4, OUTPUT);   // output
}

void loop() {
  // 1. Read the sensors
  v_D2 = readUltrasonicCm(2);   // cm
  Serial.println(String("D2=") + v_D2);

  // 2. Apply the rules
  if (v_D2 < 30) {
    writeOut(6, blink(250));
  } else {
    writeOut(6, 0);
  }
  if (v_D2 < 15) {
    writeOut(4, 1);
  } else {
    writeOut(4, 0);
  }

  delay(50);
}

Tips for building the real thing

  • The ultrasonic sensor needs 5 V; it will not run on 3.3 V.
  • Buzzer module on D6, red LED with a resistor on D4.
  • Add more LEDs (green, yellow, red) for different distances to make a bar display.
  • Mount the sensor level and facing straight back for steady readings.

FAQ

How accurate is the HC-SR04?

About ±3 mm in good conditions, from 2 cm to 4 m.

Can I make the beep faster when closer?

Yes: in code, make the beep delay depend on the distance, for example delay(distance * 10).
