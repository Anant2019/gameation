Board code (rules)

THEN / ELSE take a number or a formula such as map(A0,0,1023,0,180). ON = 1, OFF = 0, PWM = 0–255, servo = 0–180°, motor driver = −255 to 255. Uno A0/A1 read 0–5 V as 0–1023. Pi GPIO pins are digital only and are damaged above 3.3 V.
